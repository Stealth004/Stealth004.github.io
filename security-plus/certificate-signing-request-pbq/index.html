  • SAN missing requested name
  • Check SAN first.
⏰ Expired
  • Validity period ended.
  • Renew/replace certificate.
⛓ Missing Intermediate
  • Root trusted but chain incomplete.
  • Present/install required intermediate.
🗝 Key Compromise
  • Revoke old certificate.
  • Generate NEW key pair.
  • Create new CSR and certificate.
