    Wireless role map

    Supplicant = endpoint requesting access. Authenticator = AP/switch/controller controlling the port or wireless association. Authentication server = RADIUS/AAA service making or supporting the access decision. A directory or certificate authority may provide identity evidence to that AAA service.

    Personal vs Enterprise

    Personal uses a WLAN secret/passphrase; WPA3-Personal uses SAE. Enterprise uses 802.1X/EAP with an authentication server such as RADIUS. Do not confuse a WLAN PSK with the RADIUS shared secret between the NAS/controller and RADIUS server.

    PEAP vs EAP-TLS

    PEAP-style training scenario: individual username/password credentials protected inside a tunneled EAP exchange. EAP-TLS: certificate-based mutual authentication and a strong fit for centrally managed endpoints with a PKI.

    2.4-GHz channel clue

    For the simplified North American 20-MHz 2.4-GHz exam model, channels 1, 6, and 11 are the familiar non-overlapping choices. This rule is not a universal channel plan for 5-GHz or 6-GHz networks.
