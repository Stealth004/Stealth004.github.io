      Keep these closed during an exam-style attempt.

      Exam logic — rule order

      If a rule looks correct but traffic still fails, inspect the rule above it. A top-down firewall can match an earlier broad deny/permit before reaching the intended rule.

      Exam logic — scope

      If traffic works but exposure is too broad, the problem is scope—not availability. Narrow source/destination objects rather than adding another permit.

      Exam logic — WAF path

      HTTPS does not make direct backend access acceptable. If architecture requires Internet → WAF-PROXY → API-SRV, an Internet → API-SRV permit bypasses the enforcement layer.

      Memory aid

      REQ → FLOW → MATCH → ORDER → FIX → TEST. Build Mode asks you to create policy; Diagnostic Mode asks you to explain why an almost-correct policy behaves incorrectly.
