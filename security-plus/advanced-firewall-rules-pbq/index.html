    Topology Training — trace the packet before writing the rule
    1. Identify directionIngress approaches a protected destination. Egress leaves a protected host. Management may originate remotely but still needs a restricted source.
    2. Find the enforcement pointThe firewall between source and destination is the policy enforcement point. Configure the firewall directly protecting that server.
    3. Use least privilegeMatch the exact source, destination, and service. Encryption such as SSH or HTTPS protects content; it does not authorize every source.
    4. Order top-downPlace specific permits before the final logging deny. A broad earlier rule can shadow a correct later rule.
    5. Remember stateA stateful firewall permits return traffic for an established session. Do not create duplicate reverse-direction permits.
    6. Distinguish deniesAn implicit deny is the fallback. An explicit final deny is useful when the task requires logging or auditing denied traffic.
